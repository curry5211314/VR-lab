## 1. 使用原则

1. **占位优先**：先用 Unity 基础几何体和纯色材质跑通 S0–S3、10 次命中与结算，不被素材卡住。
2. **存放位置**：
   - 只属于本链路的模型、贴图、音效、动画 → `Assets/Chains/Rescue_Care/`（建议按 `Art/Models`、`Art/Materials`、`Art/Prefabs`、`Audio` 分子目录）；
   - 救助站两条链路共用的资源 → `Assets/Themes/Rescue/`；
   - 不往 `Assets/Res/` 加新文件，不移动或重命名已有资源。
3. **命名**：统一 `RC_` 前缀，例如 `RC_Char_Deer`、`RC_Prop_Bedding_Dirty`、`RC_VFX_Hit`、`RC_SFX_Hit`。
4. **授权**：外部素材记录来源与许可证；课程源码和未授权资源不外传。

## 3. 占位实现方案

### 3.1 小鹿

- 身体：Capsule，缩放约 `(0.5, 0.6, 0.9)`；头：Sphere；腿：4 个 Cylinder。
- 颜色：棕色 `#8B5A2B`，腹部浅色 `#D2B48C`。
- 反应：用 DOTween 做 `DOLocalMoveY` / `DOScale`，不依赖 Animator，先保证状态变化可见。

### 3.2 垫料

- 10 个 Cube，尺寸 `0.6 × 0.08 × 0.6`，左右各 5 个，围绕小鹿摆成两排。
- 两个材质：`RC_Mat_Bedding_Dirty`（深褐）、`RC_Mat_Bedding_Clean`（米黄）。
- 命中时只替换对应块的材质，不做整体切换，保证“逐块清洁”的反馈。

### 3.3 围栏与护理点

- 围栏：6 段 Cube 立柱 + 2 根横杆，木色；或用 `PUI4.0` 现有低多边形围栏。
- 护理点：药箱（Cube）、水盆（Cylinder 压扁）、毛巾（Quad），放在小鹿两侧，作为视觉引导。

### 3.4 特效与音效

- 命中：短粒子 + `Star Up0.wav`，延迟不超过 0.3 秒。
- 失误：世界空间提示牌“保持上臂贴身，前臂向内旋转”2 秒 + `Click.wav`。
- 完成：暖色粒子 + `收集.mp3`。

## 4. 导入与性能约定

| 类型 | 约定 |
| --- | --- |
| 模型 | Scale 1；关闭 Read/Write；面数尽量低，单模型不超过 5k 三角面 |
| 贴图 | 1024 或 2048；URP/Lit；关闭不必要的 Mip 变化 |
| 音效 | 短音效 Decompress On Load；BGM Streaming；统一音量后混音 |
| 粒子 | 同屏粒子系统不超过 5 个；命中粒子生命周期不超过 1 秒 |
| Prefab | 无 Missing Script；所有引用在 prefab 内自包含 |
