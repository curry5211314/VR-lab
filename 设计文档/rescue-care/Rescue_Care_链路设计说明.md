# 内旋护理（Rescue_Care）链路设计说明

> 主题：野生动物救助站
> 动作：体侧内旋（双侧，左右各 5 个，共 10 个目标）
> 目标年龄段：18–30 岁
> 负责人：欧阳煐杰
> 版本：v1.0（2026-11-26）
> 对应计划：B2 设计定稿；B4/B5 按本文实现

---

## 1. 体验目标

玩家扮演野生动物救助站的护理员。小鹿受伤后蜷缩在脏污的垫料上，玩家通过**双侧体侧内旋**触碰左右两侧的发光护理目标，逐步清洁垫料，让小鹿从蜷缩恢复到站立。

- 动作是推进故事的核心手段，不能用普通按钮代替。
- 单轮 10 个目标（左手 5、右手 5），约 1–2 分钟。
- 每次命中都必须有可见反馈；失误只提示，不扣进度、不倒退阶段。

---

## 2. 年龄段适配（18–30 岁）

| 项目 | 设计 |
| --- | --- |
| 目标高度与距离 | 以肩高为基准：高度在肩下 5 cm 到肩上 15 cm，前伸 35–55 cm，左右各偏 15–25 cm。沿用现有臂长参数（默认约 60 cm），不为成年用户额外缩小 |
| 文案与语音 | 短句；首次出现“体侧内旋”时用一句白话解释；语音正常语速，不使用儿童化措辞 |
| 单轮强度 | 10 个目标、1–2 分钟；默认难度 1（失误超时 6 秒），难度 0 / 2 对应 8 / 4 秒 |

---

## 3. 故事状态机

状态由 `StoryStateController` 管理，阶段只随命中前进，不因失误倒退。

| 阶段 | 名称 | 进入条件 | 场景表现 | HUD |
| --- | --- | --- | --- | --- |
| S0 | 脏污待护理 | 轮次开始，`ResetToStart()` | 10 块垫料深褐、灰尘粒子、小鹿低头蜷缩、灯光偏冷 | 阶段 0/3，命中 0/10 |
| S1 | 开始清洁 | 命中第 3 个目标 | 前 3 块垫料变浅、灰尘减少、小鹿抬头 | 阶段 1/3 |
| S2 | 基本恢复 | 命中第 6 个目标 | 6 块垫料清洁、围栏灯变暖、小鹿站立 | 阶段 2/3 |
| S3 | 恢复完成 | 命中第 10 个 / `OnRoundComplete` | 全部垫料干净、灰尘停止、小鹿轻跳、完成音效 | 阶段 3/3 + 结算面板 |

失误不改变阶段；`OnRoundAbort` 时恢复到 S0 的表现。

---

## 4. 目标与垫料映射

每侧 5 个目标由 `StarCreater.TiCeNeiXuan()` 生成：先 3 个弧线目标（index 0–2），再 2 个上方目标（index 3–4）。

| 侧别 | index | 生成顺序 | 对应垫料 |
| --- | --- | --- | --- |
| 左（玩家左手侧） | 0–2 | 弧线 3 个 | L1–L3 |
| 左（玩家左手侧） | 3–4 | 上方 2 个 | L4–L5 |
| 右（玩家右手侧） | 0–2 | 弧线 3 个 | R1–R3 |
| 右（玩家右手侧） | 3–4 | 上方 2 个 | R4–R5 |

映射公式：`垫料序号 = (side == Left ? 0 : 5) + index`，共 10 块。

- 命中时把对应垫料材质从“脏污”切换为“清洁”，并播放一次粒子和音效。
- 护理点（药箱、水盆、毛巾）是装饰，放在小鹿两侧，不参与判定。
- 左右各 5 块垫料的位置要在 B5 按实际星星生成位置校准；prefab 不定义目标锚点。

## 5. 成功、失误与星级

| 事件 | 处理 |
| --- | --- |
| 命中 | 命中数 +1；第 3 / 6 个命中推进到 S1 / S2；点亮对应垫料，反馈延迟不超过 0.3 秒 |
| 失误（超时） | 显示“保持上臂贴身，前臂向内旋转”2 秒并播放提示音；不扣命中、不倒退阶段、不重置目标 |
| 完成 | 命中数 + 失误数达到 10 时结算；`OnRoundComplete` 进入 S3 |
| 星级 | 0 失误 3 星；1–2 次失误 2 星；3 次及以上或未完成 1 星（沿用 `StoryRoundController`） |
| 重玩 | 清空旧目标与垫料状态，回到 S0；不叠加上一轮目标 |

最后一颗目标失误也能正常结算，沿用现有 `Star` 的失误上报逻辑。

## 6. 完整流程

```
Bootstrap
  → 选择「野生动物救助站」
  → Theme_Rescue 链路菜单选择「内旋护理」
  → 引导 3 步
  → 开始（默认难度 1）
  → 左右各 5 个目标
  → S0 → S1（3 命中）→ S2（6 命中）→ S3（10 命中）
  → 结算（命中 / 失误 / 用时 / 星级）
  → 重玩 / 返回链路菜单 / 返回主题选择
```

引导文案（B7 细化）：

1. 情境：小鹿受伤后垫料脏污，需要清理护理区。
2. 动作：双臂贴身、屈肘约 90°，前臂向内旋转，触碰左右两侧发光目标。
3. 失误：保持上臂贴身；漏掉目标只提示，不扣进度。

## 7. 技术落点

| 项目 | 位置 / 说明 |
| --- | --- |
| 流程脚本 | `Assets/Chains/Rescue_Care/DeerCareFlow.cs`，`TargetCount = 10` |
| 动作适配 | `Assets/ActionCore/TiCeNActionAdapter.cs`，`Action = TiCeNXuan_Both`，`endIndex = 4` |
| 状态访问 | 计划给 `StoryContext` 增加 `stateController` 字段，并在 `Awake` 中 `GetComponent<StoryStateController>()`；这是公共层小改动，需先在群里同步 |
| 命中/失误来源 | `Star.cs` 已通过 `StoryActionBus` 上报，Flow 不重复 Raise |
| 目标生成 | 场景内 `starCreater_L_tcNx` / `starCreater_R_tcNx` 运行时生成；prefab 只做视觉与垫料 |
| 禁止改动 | `Assets/Scripts/UDP_Pad`、`Star.cs` 碰撞判定、`MainControl` 目标顺序、其他链路 |

约束：

- 不修改 `Theme_Rescue.unity` / `Theme_Market.unity`；所有新内容放进链路 prefab。
- 链路 prefab 不 `Find` 场景对象；外部引用统一走 `StoryContext`。
- 新 UI 不另起 Canvas，必要提示优先在 prefab 内用世界空间文字或音效实现。
- 目标数与适配器保持一致：`(4 + 1) × 2 = 10`。

## 8. 验收标准

- [ ] 从 Bootstrap → Theme_Rescue → 链路菜单可进入「内旋护理」。
- [ ] 引导可翻页并开始；开始后左右各生成 5 个目标。
- [ ] 10 次命中依次进入 S1、S2、S3，结算 3 星。
- [ ] 每次命中对应垫料变干净，有粒子/音效反馈。
- [ ] 漏掉目标只提示，不扣进度；多次失误按规则降星。
- [ ] 重玩不叠加旧目标；返回链路菜单/返回主题选择正常。
- [ ] Console 无 error；CSV 开始/结束记录正常。

## 9. 风险与待确认

| 风险 / 待确认 | 处理 |
